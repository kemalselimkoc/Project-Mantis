2. YOUR RESPONSIBILITY
Use Mantis only on computers you own or are authorized to administer. Every
change is shown first and applied only after you confirm, and most changes can
be undone from inside the app. Even so, Windows installations differ: keep
backups of important work and, where possible, create a System Restore point
before changing services, startup items, registry-based tweaks, the hosts file,
power settings or security settings.

3. CLEANUP AND FILES
Cleanup deletes files only from its documented cache/temp allowlist. Locked or
inaccessible items are skipped. Close Adobe applications before cleaning their
caches. The disk tools send files to the Recycle Bin, never delete them
permanently.

4. SECURITY CHECK-UP
The Security Check-Up is an advisory audit, not an antivirus or a guarantee of
security. It does not delete or quarantine files; it reports findings and
directs you to Microsoft Defender. A clean result does not mean a system is
free of threats.

5. LOCAL NETWORK SCAN
The network scan only contacts devices on the local subnet your computer is
connected to and never scans internet hosts. Scanning networks without
permission may be unlawful. Run it only on networks you own or have explicit
permission to test. Mantis asks you to confirm this before each session's scan.

7. OTHER FEATURES
Memory optimization trims process working sets; Windows may reload data later.
Game Mode changes the active Windows power plan and attempts to restore it.
Audio Balance changes the per-channel volume exposed by the active Windows
output. It is an accessibility convenience, not a medical device or calibrated
hearing aid. Use a comfortable master volume and avoid sudden loud output.
Ghost Overlay changes ordinary Windows styles only on a user-selected supported
browser Picture-in-Picture window or media player. It does not inject code into,
read memory from, hook, automate, or modify games. Compatibility with every
game or third-party anti-cheat system cannot be guaranteed. Stop using overlays
if a game's rules prohibit them or the game reports a conflict.
Grab Text reads text from the screen offline. Respect copyright and the privacy
of others when capturing or translating content you do not own.
